# Design Spec: "Aurora Glass" habit tracker

Futuristic, calm, high-contrast. Bento-grid layout, glass cards, soft glow. Dark theme is the default. Light theme follows the pastel look: white cards, big radii, soft tinted tiles. Each habit's own color is the only strong color on screen; everything else is neutral.

## 2. Habit color rules (important)
- Habit color is used for: check ring/fill, progress bars, chart lines, heatmap cells, dots, tile tint, glow.
- Habit color is NEVER used for body text on a surface. Names stay text-primary.
- `readableColor(hex, theme)` in src/lib/color.ts: if contrast against the surface is below 3:1, raise lightness (dark theme) or lower it (light theme) until it passes. Use this for every foreground use of a habit color, so very dark or very light custom colors still show up.
- Tints: `color-mix(in srgb, <color> 22%, transparent)` for tile backgrounds, 35% for borders, 55% for glows.

## 3. Typography
- Headings and big numbers: "Space Grotesk" (Google Font). Body and UI: "DM Sans".
- Greeting/page title 32/40, weight 700. Hero numeral 56/56, weight 700, tabular-nums. Section title 18/24, 600. Habit name 17/24, 600. Body 15/22, 400. Caption 12/16, uppercase, tracking .08em, text-muted.

## 4. Shape, spacing, depth
- Radius: app shell 32px, cards 28px, tiles 24px, inputs 16px, buttons/chips/pills fully round.
- 4px spacing scale. Card padding 20px mobile, 24px desktop. Grid gap 16px mobile, 20px desktop. Page padding 16px mobile, 32px desktop. Max content width 1280px.
- Never use flat black cards with only a border. Every card has glass + soft shadow.

## 5. Layout shell
- Desktop (>=1024px): floating rounded shell inset 16px from the viewport edges over the aurora background. Slim 72px left rail with:
  - Top: logo mark (48px) in a glass tile; wordmark "Habit Tracker" present but visually hidden on the narrow rail.
  - Middle: Today, Overview, Settings as circular 48px icon buttons. Active: accent-gradient fill with glow. Inactive: surface-2 circle.
  - Bottom: Profile — the user's 48px avatar circle (icon fallback), active state with an accent-gradient ring when on /profile. No theme toggle in the rail; the theme toggle is a compact sun/moon icon button on the Today header.
- Mobile: no rail. Floating bottom dock, glass pill, 64px high, 16px from bottom and sides, 3 icon buttons (Today, Overview, Settings), respects safe-area inset. Content gets bottom padding so the dock never covers it. Profile is reached via the avatar in the Today header; Settings has a "View profile" link.
- Header on every page: greeting block (avatar, time-of-day greeting, "Hi, <name>", date) on the left, primary action pill on the right.

## 6. Components
- **Primary button:** 48px, accent-gradient, white text, glow shadow (0 10px 30px -8px accent at 60%). Hover: brightness 1.08 and translateY(-1px).
- **Secondary button:** glass pill, border, same height.
- **Habit tile (Today):** min-height 132px, background linear-gradient(145deg, habit 22%, habit 6%), border habit 35%. Top-left 52px circular check button (44px tap target; 42px in the compact tier, 30px in the <=110px tier, 26px in icon tiles): pending = 2px habit-color ring; done = filled habit color, white check, glow; **skipped day = dashed muted habit ring (45% color-mix), no pop/burst**. **A habit's optional emoji is painted inside that same check ring (the checkbox slot): pending/skipped sit on a light habit tint (14% / 8%) and dim to 70% when skipped; done keeps the emoji on the solid habit fill and adds a small white check badge in the bottom-right corner so completion stays obvious — the ring-pop/burst animations are unchanged.** Habit name below (plain text, not a link), then a **"Skipped" caption chip when the day is skipped** (muted, before the streak chip), then the streak chip (flame icon + number) on the right. A skipped tile is muted overall (50% saturation, 80% opacity), its numeric bar is hidden and its value button shows "Skipped" instead of the number (never a 0%-miss), and it keeps its slot in the ring layout. Numeric habits show a 6px rounded progress bar in the habit color plus "12 / 30 min" (value / target unit, never repeat the number). Edit icon appears on hover and is always visible on mobile. **A "more" icon button (three dots) sits next to the pencil — same size (44px, hover-visible on desktop) — opening a small glass `popover-solid` menu with "Skip \<day\>" / "Undo skip" for the selected date, closing on outside click/Escape (CompletionCard popover pattern); the tile lifts to `z-10` while the menu is open, and the menu is disabled in reorder mode.** Below the ~232px container-query threshold only the more button shows, and the menu gains an "Edit habit" item (mirrored in JS with a ResizeObserver). Hover: lift 2px, border brighter. **The whole tile is a stretched link to the habit's detail/overview page** (absolute-inset overlay, sr-only label); exactly four controls paint above it and keep their own behavior: the check button (toggle), the pencil (edit page), the more menu (skip/undo) and the numeric value button/editor (log value). In reorder (jiggle) mode the overlay link is inert and the pencil/menu are disabled. **Dense columns (5-up ≥1280px):** the grid item is a CSS container; below a ~232px column the tile auto-compacts (min-height 104px, 14px padding, 42px check ring, smaller name/streak/value type) and invisible `::after` pads keep every control's effective tap target at ≥44px — full density applies on 1-up mobile columns.
- **Progress rings (hero):** concentric SVG rings driven by `src/lib/rings.ts` — ring order follows habit order from the outside in, exactly as `layoutRings` returns it: up to 7 habits each get a full ring of their own color (outermost = first); with more than 7, the first habits share the outer rings (equal arcs, up to 4 per ring: 50%/33%/25%…) and the remaining habits get full inner rings, capped at 28 shown habits. Each slice carries a 12%-opacity track arc and a progress arc (boolean = whole arc when done; numeric fills value/target clockwise from the slice start), 6px rule gaps with round caps. Geometry comes from `ringGeometry`, which packs the rings edge to edge between a ≥96px free center and the rim and centers them in the band: strokes are ~12px for 1–5 rings and thin to ~8.5px at 7, while the center hole shrinks as habits (rings) are added — from ~156px at one ring down to its 96px minimum — so there is never a large vacant middle. Center text counts ALL active habits ("3 / 12 done today") minus the habits skipped that day, and a skipped habit's tooltip says "skipped" (a neutral vacation day says "vacation", unless the entry is done — done wins); the numeral scales down for big counts and the caption is hidden when the center gets tight. **Vacation mode:** while the logical today is inside a break the hero passes `paused`, so the center shows "Paused" instead of the done/total pair. Hovering or tapping an arc shows a small glass tooltip (habit-color dot + name + "done"/"3 of 5 min"); targeting is a nearest-arc polar picker with a ≥24px tolerance — taps never toggle. Per-arc `aria-label`s plus a `role="img"` summary on the SVG.
- **Stat tile:** glass, caption label on top, big numeral, small delta chip with arrow (success or danger).
- **Chips (habit toggles):** 36px pill, small dot in habit color. Selected: habit 20% fill and habit 40% border. Unselected: 50% opacity.
- **Range switch:** segmented control with a sliding accent pill behind the active option, 40px high, equal-width segments, white-space nowrap. Under 400px uses short labels ("30d", "90d", "1y"). An optional `compact` prop (habit-form phone rows) renders it 36px high, 13px text, ~170px wide; the default stays untouched elsewhere.
- **Color picker:** 10 preset round swatches (32px) with a ring on the selected one, plus a "custom" swatch that opens the native color input.
- **Inputs:** 52px, surface-2, 16px radius, 1px border, accent focus ring with glow.
- **Emoji picker (habit form):** a 48px glass pill showing the current emoji inside the habit-colored ring (or 🙂) opens the full Unicode picker (`emoji-picker-react` v5, lazy-loaded chunk). Desktop: an anchored `popover-solid` panel (~392px wide, clamped to the viewport, flips above the trigger when the page is short). Phone: a 62dvh→**70dvh bottom sheet with a grab handle** over a dim backdrop, so the keyboard never hides the grid. The phone form layout (`HabitFormMobile`) additionally has a `circle` trigger — a 52px round glass button showing the chosen emoji or a faint smiley-plus icon — that opens the same picker. Cells are **44px** (28px glyph + 8px padding) with the search field at 44px and a horizontally scrollable 40px category strip; native emoji rendering, skin tones, recents, and search. Picker CSS variables are mapped to our tokens (surface-2 search, accent highlight, surface-solid sticky labels; `color-mix` hover), following the theme through `colorScheme`. Header shows "Choose an emoji" + Remove/Done; outside click, Escape and Done close it and return focus to the opener. The free-text input next to it stays for pasting any emoji (desktop layout).

## 7. Charts
- Line chart: monotone smooth curves, 2.5px stroke in the habit color, gradient area fill (habit 30% to 0%), soft glow via drop-shadow(0 0 8px habit 50%). Horizontal grid only, dashed, chart-grid color. No vertical grid, no axis lines. Axis labels 12px chart-axis.
- Active point: 8px dot with a 3px white ring, as in the reference. Tooltip: glass card, 16px radius, colored dot, habit name, value.
- Bars: 10px wide, fully rounded tops, 6px gap, habit color; today's bar glows.
- **Heatmap (HabitDetail):** 14px cells, 4px radius, 4px gap; levels at habit 12%, 35%, 65%, 100%; the top level has a small glow. Month labels above, weekday labels left; month labels are thinned (`sparseMonthLabels`) — a month that starts within ~3 columns of the previous label is dropped and the roomier month keeps its name (no DEC/JAN collisions). **Skipped days render as neutral outlined cells** (transparent fill, 1.5px `color-mix(in srgb, fg 40%, transparent)` border — never a 0%-miss fill), the tooltip/aria text says "Skipped", and a small legend sits under the grid (Done in full habit color; Partial at 35% for numeric habits; Skipped as the outlined sample; **Vacation as a second outlined sample** — a vacation day is neutral with the same look, and a done entry on a vacation day paints normally; Not completed in surface-2). **Tapping a day cycles empty → done → skipped → empty** via `nextDayAction`/`dayActionFor` in `src/lib/dayStatus.ts` (a done-but-below-target numeric row is "empty", so the first tap marks it done at target).
- Completion card (Today): **single-color intensity ramp** — the user picks ONE color for the whole card (palette popover with the standard color presets + native picker), and every day cell/bar is filled with that color via `color-mix(... N%, transparent)` where N follows the day's completion share (0 = neutral track, then 20…100%). It anchors to **logical today** (the day-start-adjusted real day, independent of the backfill date pill), is non-interactive, and the chosen view + color persist in localStorage (`completion-view` / `completion-color`, default `#6366F1`).
- Charts always have an empty state (soft illustration-free message plus "Check in a habit to see your score").

## 8. Page layouts

Header row: "This week/This month/This year" title + "% done per day" caption, a **Week | Month | Year segmented pill** and a palette button opening the color picker popover. ## 9. Motion
- Easing cubic-bezier(.2,.8,.2,1). Durations: hover 160ms, page content 300ms.
- Page load: cards fade up 12px with 40ms stagger.
- Check-in: ring-pop (scale 1 to 1.15 to 1 in 280ms) plus a short burst of 6 small dots in the habit color; the hero ring arcs morph to their new fill (stroke-dasharray) in 400ms; big numbers count up.
- Rings and chart lines draw in on first render (900ms).
- Reorder: other tiles slide to make room at 200ms (dnd-kit default easing); the hero rings animate radius, slice position (rotation) and fill in 400ms.
- Respect prefers-reduced-motion: disable bursts and draw-ins; in reorder mode the wiggle becomes a static dashed outline and drags still work.

## 10. Do and don't
- Do keep neutral surfaces and let the habit colors carry the color.
- Do keep tap targets at least 44px.
- Don't use habit colors for text, uppercase habit names, or flat black card backgrounds.
- Don't add new dependencies except an icon set already in use. Animations are CSS and SVG only.
- Don't leave a page as one narrow centered column on desktop; use the grid.

## 13. Dialogs
All confirmation dialogs use the shared `ConfirmDialog` component (`src/components/ConfirmDialog.tsx`), rendered via `createPortal` into `document.body` so no parent with `backdrop-filter`, `transform`, `filter`, or `overflow` can break the blur.

- **Scrim:** full-screen layer behind the dialog. `rgba(4,6,14,0.55)` in dark, `rgba(15,23,42,0.28)` in light, plus `backdrop-filter: blur(10px) saturate(120%)`. Fades in over 160ms. Clicking the scrim cancels.
- **Dialog panel:** glass, not solid. Width `min(420px, calc(100vw - 32px))`, radius 28px, padding 24px.
  - Dark: background `linear-gradient(145deg, rgba(34,38,64,0.78), rgba(14,18,36,0.72))`; border `1px solid rgba(255,255,255,0.14)`; `backdrop-filter: blur(28px) saturate(150%)`; shadow `inset 0 1px 0 rgba(255,255,255,0.10), 0 30px 80px -20px rgba(0,0,0,0.7), 0 0 60px -20px color-mix(in srgb, var(--accent) 35%, transparent)`.
  - Light: background `linear-gradient(145deg, rgba(255,255,255,0.88), rgba(241,244,246,0.80))`; border `1px solid rgba(15,23,42,0.10)`; same blur; shadow `0 24px 60px -24px rgba(15,23,42,0.30)`.
  - `@supports not (backdrop-filter: blur(1px))` raises panel background opacity to 0.94 so content never shows through in browsers without blur.
  - A thin 2px gradient line (accent-gradient, 40% opacity) along the top edge; hidden for the danger variant, which uses a soft danger-colored glow instead.
- **Content:** title in heading font at 22px; description in sentence case at 15px, `text-secondary` (not uppercase, no letter-spacing). Buttons right-aligned in a row: Cancel as secondary ghost pill, confirm as danger pill (soft danger tint `rgba(251,113,133,0.14)`, danger border and text, stronger hover fill). Both 44px high. Under 400px, buttons stack full width, confirm on top.
- **Behavior & accessibility:** `role="alertdialog"` with `aria-labelledby` and `aria-describedby`; focus moves to Cancel on open; focus trap inside; Escape cancels; focus returns to opener on close; body scroll locked while open. Entry animation: scale 0.96 to 1 plus fade over 200ms with cubic-bezier(0.2, 0.8, 0.2, 1); disabled under `prefers-reduced-motion`.
- Used for: sign-out confirmation on the Profile page, remove-photo confirmation in the Profile banner.
- **ImportPreviewDialog** (`src/components/ImportPreviewDialog.tsx`) reuses exactly this pattern for the Settings backup import: `role="dialog"` (not `alertdialog` — it holds interactive content), `aria-labelledby` to the "Import backup" title, portal + `.dialog-scrim`/`.dialog-panel` classes, focus → Cancel on open, focus trap, Escape cancels (ignored while busy), scroll lock, focus returns to the opener, entry animation under the same reduced-motion rule. The confirm action (Import) is the accent pill and is disabled — with the "Nothing to import" notice — when the plan is empty and no optional restore is selected. The plan grid gains a **"Breaks (vacation)" cell** ("N new · M existing") whenever the file contains `vacationPeriods`, and the busy button shows "Restoring breaks…" while the vacation-phase inserts run (between habits and entries).
